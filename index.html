07 Progress readout
07b Date numbers

The 1st of each month shows its three-letter abbreviation (Jul, Aug…) in the month color; every other day shows its date (2–31) in the day color. Size is a percentage of the dot's diameter.

08 Background image & glass

A chosen file lives in this browser only — it shows in the preview and the downloaded PNG, but the daily Shortcut runs on a server and can't reach it. For the live wallpaper, commit the image into your repo and paste its public URL. Blur is applied in the preview and in Download PNG; the server renders the panel as tint only, so pre-blur the photo if you want frosted glass on the live wallpaper.

09 Lock screen guides

Guides only — never drawn into the wallpaper or the downloaded PNG. Apple doesn't publish these coordinates, so the defaults are measured from iPhone 15 screenshots. Take a screenshot of your own lock screen and nudge the two sliders until they line up.

10 Website storage

Checking…

Once saved, the Shortcut URL below never needs changing again — the plain /api/wallpaper address reads whatever you last saved, from any browser. Config codes stay as a fallback.

11 Sync, export & Shortcut

  1. Get Contents of URL → paste the Shortcut URL.
  2. Convert Image → Contents of URL → PNG.
  3. Set Wallpaper → Converted Image → Lock Screen, Preview off.
  4. Automations → Time of Day → 00:00 daily → Run Immediately.

Stuck? Add &debug=1 to the Shortcut URL. It returns text instead of an image and tells you what the server computed.
